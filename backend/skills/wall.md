CAD 图纸结构墙识别（PNG 格式）- 像素级分析方案
本方案针对 PNG 格式的 CAD 图纸，以像素分布规律为核心，通过预处理、特征提取、几何验证三步完成结构墙的精准识别，充分利用 PNG 格式对 CAD 图案纹理、几何特征的完整保留特性。
一、像素级预处理：强化图案与背景的区分度
核心目标：消除干扰，突出结构墙填充图案的像素特征（PNG 格式下纹理特征完全保留）。
灰度化：将彩色 PNG 图像转为单通道灰度图，消除非必要色彩干扰（CAD 图纸以单色为主）；
自适应二值化：根据局部像素亮度调整阈值，将图案纹理（深色 / 斜线）与背景（白色）分离，解决 PNG 图片压缩失真、背景亮度不均的问题；
降噪处理：通过中值滤波 / 高斯滤波去除扫描噪点、线条锯齿，仅保留图案核心像素纹理；
形态学操作：采用膨胀 / 腐蚀组合运算，强化图案的连续纹理特征（如 ANSI31 斜线的连通性、AR-CONC 颗粒的聚集性）。
二、图案特征提取：基于像素分布规律的模板匹配
核心目标：针对 CAD 典型填充图案的像素排列模式，设计特征模板并计算匹配度。
特征模板设计（像素维度）：
ANSI31（45° 斜线）：统计像素梯度方向，计算 45°/135° 方向线条的像素占比，匹配斜线排列规律；
AR-CONC（混凝土颗粒）：分析随机分布的高灰度值像素簇的密度、分布范围，匹配颗粒状像素特征；
SOLID（实心填充）：检测连续的高灰度值连通域，筛选面积≥阈值的像素块，匹配实心填充的像素特征；
特征匹配：计算待检测区域像素分布与标准模板的相似度，筛选出高匹配度的候选区域。
三、几何特征验证：筛选符合结构墙特征的像素区域
核心目标：基于 PNG 中保留的几何像素特征，排除非墙区域，精准定位结构墙。
轮廓提取：从候选区域中提取像素级轮廓，筛选 “双线矩形 / 多边形”（结构墙的核心几何特征）；
尺寸验证：将像素尺寸按图纸比例换算为实际尺寸，验证轮廓的宽高比、厚度（匹配 CAD 结构墙常见厚度 100/200/300mm）；
干扰排除：剔除柱子、文字框等非墙区域（此类区域虽可能有实心 / 斜线填充，但几何尺寸 / 轮廓不符合结构墙特征）。
四、结果输出：结构化呈现识别结果
可视化标记：在 PNG 图像上绘制矩形框，标记识别到的结构墙像素区域；
数据输出：输出匹配的图案类型（ANSI31/AR-CONC/SOLID）、结构墙的像素坐标 / 实际尺寸。
总结
方案核心逻辑：以PNG 格式保留 CAD 像素特征为前提，通过预处理强化纹理、特征提取匹配图案、几何验证筛选墙体，三步完成识别；
关键适配点：预处理环节的自适应二值化、降噪等操作，专门解决 PNG 图片的压缩失真、亮度不均问题；
特征核心：所有识别环节均围绕 “像素分布规律” 展开（斜线方向、颗粒密度、实心连通域、几何轮廓的像素特征），确保识别精准性。
